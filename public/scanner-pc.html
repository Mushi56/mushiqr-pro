OS Keyboard Wedge — Type into Excel, POS, Retail Software
⚡ To type scanned barcodes directly into Excel, POS software, Notepad, or any active app on your computer, use one of the helpers below. They act as a virtual keyboard wedge just like a physical scanner gun.

Run this command in Windows PowerShell to connect and start typing instantly. No installation required!

# Copy & paste this block into Windows PowerShell: $SessionId = "paste-your-session-id-here" $Uri = "wss://ntfy.sh/$SessionId/ws" Add-Type -AssemblyName System.Windows.Forms $ws = New-Object System.Net.WebSockets.ClientWebSocket $ws.ConnectAsync($Uri, [System.Threading.CancellationToken]::None).Wait() Write-Host "🔫 Mushi Scanner Active! Type in any active window (Excel, POS, etc.)." -ForegroundColor Green $buf = New-Object Byte[] 1024 while ($ws.State -eq 'Open') { $seg = New-Object ArraySegment[Byte] -ArgumentList @(,$buf) $res = $ws.ReceiveAsync($seg, [System.Threading.CancellationToken]::None).Result $raw = [Text.Encoding]::UTF8.GetString($buf, 0, $res.Count) if ($raw -match '"event":"message"') { $val = (ConvertFrom-Json $raw).message [System.Windows.Forms.SendKeys]::SendWait($val) [System.Windows.Forms.SendKeys]::SendWait("{ENTER}") Write-Host "Typed: $val" } }

Install requirements: pip install websocket-client pyautogui, then run this python script.

# Install once: pip install websocket-client pyautogui import json, websocket, pyautogui, time SESSION_ID = "paste-your-session-id-here" def on_message(ws, message): data = json.loads(message) if data.get('event') == 'message': barcode = data['message'] time.sleep(0.1) # brief delay so window stays focused pyautogui.typewrite(barcode, interval=0.02) pyautogui.press('enter') print(f"✓ Typed: {barcode}") ws = websocket.WebSocketApp( f"wss://ntfy.sh/{SESSION_ID}/ws", on_message=on_message ) print("🔫 Scanner Gun active — waiting for barcodes...") ws.run_forever()
